# 常用函数 {#s-760ce10e6ec0}

常用的整数运算：模快速幂、整数平方根、最小公倍数、整数对数，以及向上 / 向下取整的除法。按所需运算选取对应函数，使用前核对输入范围和中间乘积。

**使用：** `mypow(n, k, p)` 计算非负指数的模幂，时间 $O(\log k)$，先保证底数已归一化。`mysqrt(n)` 返回整数平方根，当前乘法校正适用于 $0 \le n \le 10^{18}$。`mylcm` 先除后乘，但结果仍须在 `int` 范围内。

> `mypow` 的参数与累乘器是 `i64`：模数 $p \le 3 \times 10^{9}$ 时 `n * n` 不溢出；更大的模数改用 `__int128` 或数论章的防爆模乘。

**使用：** `log2floor(x)` / `log2ceil(x)` 返回整数对数的下取整 / 上取整，要求 `x > 0`。模板循环版的 `chk * 2` 也须可表示，接近类型上限时应使用位运算实现。内建函数版按 `int` 位宽计算；处理 `i64` 时使用对应的 `clzll` 等函数并调整位宽。

**边界：** `floor` / `ceil` 分别向负无穷 / 正无穷取整，除数必须非零；中间的 `A + B - 1` 仍可能溢出，大数场景需要更宽的中间类型。
