# 康拓展开 {#s-c25f14039873}

  排列与其字典序排名互转。普通解 $\mathcal{O} ( n^{2} )$，树状数组解 $\mathcal{O} ( n \text{log} n )$，答案常取模。

## 正向展开普通解法 {#s-f9f3a482a9d7}

  将一个字典序排列转换成序号。例如：12345-\>1，12354-\>2。`f[]` 用 `int`，只适于 $n \le 12$；更大用下一节取模版。`kangtuo` 读全局 `str`。

## 正向展开树状数组解 {#s-b71e921a81aa}

  给定一个全排列，求出它是 1 ~ $n$ 所有全排列的第几个，答案对 $998244353$ 取模。

答案就是 $\sum_{i = 1}^{n} \text{res}_{a_{i}} ( n - i ) !$ 。$\text{res}_{x}$ 表示剩下的比 $x$ 小的数字的数量，通过**树状数组**处理。复杂度 $\mathcal{O} ( n \text{log} n )$。`N`、`mod` 按题目改。

## 逆向还原 {#s-468bf6c93b52}
