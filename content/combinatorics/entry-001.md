# 组合数 {#s-735e131f571b}

  $\binom{n}{k} = n ! / ( k ! ( n - k ) ! )$，选 $k$ 个。模质数：预处理阶乘逆后 $\mathcal{O} ( 1 )$，或 Lucas 把 $n , k$ 按模拆开。模任意：质因数分解或杨辉。非法下标当 $0$。

## debug {#s-4205345dd4b8}

  提供一组测试数据：$\binom{132}{66} =$ 377’389’666’165’540’953’244’592’352’291’892’721’700，模数为 $998244353$ 时为 $241 \prime 200 \prime 029$；$10^{9} + 7$ 时为 $598375978$。

## 逆元+卢卡斯定理（质数取模） {#s-5b1bf8585b18}

  $\mathcal{O} ( N )$ 预处理阶乘及逆元后 $\mathcal{O} ( 1 )$ 查询。模数必须为质数，写在模意义整数类型 `Z` 里；本板依赖 `Z`。`comb(1 << 21)` 预处理上限按题目改；查询超出时 `fac/inv` 会自动 `init` 扩表。`_inv[i]=(i!)^{-1}`，不是 $i^{- 1}$。
