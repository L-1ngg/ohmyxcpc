# 莫茨金数 {#s-10a53b32fb86}

莫茨金数 $M_n$ 计数长度为 $n$、从高度零出发并回到零、始终不低于零的上 / 平 / 下步路径，也计数圆周上 $n$ 个点之间放置若干条互不相交弦的方案。初值 $M_0=M_1=1$，下式中的 $C_k$ 为卡特兰数。

$M_{n} = M_{n - 1} + \sum_{i = 0}^{n - 2} M_{i} M_{n - 2 - i} = \frac{( 2 n + 1 ) M_{n - 1} + 3 ( n - 1 ) M_{n - 2}}{n + 2}$ $M_{n} = \sum_{k = 0}^{\lfloor n / 2 \rfloor} \binom{n}{2 k} C_{k}$ (C 为卡特兰数) 1, 1, 2, 4, 9, 21, 51, 127, 323, 835, …

### **经典应用场景:** {#s-41121563b1e3}

1.一个圆上有 n 个点,画若干条不相交弦的方案数 2.在一个二维网格从$( 0 , 0 )$走到$( n , 0 )$,$k_{1}$表示向右上走一步,$k_{0}$表示向右走一步,$k_{- 1}$表示向右下走一步 要求路径中始终不能低于 x 轴,终点必须在 $( n , 0 )$ ，问方案数。
