# Fenwick Tree 树状数组 {#s-a9d8a72c8366}

支持单点增量修改与区间求和，适合动态维护数组和。下标从 `1` 开始。

**使用：** `BIT<T>(n, in)` 从 `in[1..n]` 构造；`add(x, v)` 给位置 `x` 增加 `v`；`ask(x)` 查询前缀和，`ask(l, r)` 查询闭区间和。

**复杂度：** 当前逐点加入的构造为 $O(n\log n)$，单次修改和查询为 $O(\log n)$，空间为 $O(n)$。

**边界：** 更新位置须在 `[1, n]`，求和类型须容纳总和。差分可扩展区间加；区间覆盖应另选数据结构。

## 逆序对扩展 {#s-a3cab772ff4e}

把元素按值从小到大排序逐个插入树状数组（位置为 `idx`），`ask(idx + 1, n)` 统计**已插入且位置更靠后**的个数——即当前元素的逆序对贡献（等值元素按位置先小后大排序，不会被误计）。总复杂度 $\mathcal{O} ( N \text{log} N )$。

**接入：** 该片段是基础 `BIT` 的扩展，需要保留构造、`add` 和 `ask`；`chk` 保存待统计的原数组，当前 `get()` 的累加器和返回值仍为 `int`，逆序对可能超过其范围时须一并改成 `i64`。

## 前驱后继扩展（常规+第 k 小值查询+元素排名查询+元素前驱后继查询） {#s-3c35780c4847}

树状数组上按 $2^{k}$ 步长倍增下落，用前缀和计数定位第 $k$ 小，排名与前驱后继同理。注意，被查询的值都应该小于等于 $N$ ，否则会越界；如果离散化不可使用，则需要使用平衡树替代。

**接口：** 以频数作为权值，`add(x, 1)` / `add(x, -1)` 插入 / 删除一个值，`get(x)` 返回从 `1` 开始的排名，`kth(k)` 返回第 `k` 小，`pre` / `suf` 查询严格前驱 / 后继。示例操作编号 `1..6` 按此顺序对应。

**边界：** 删除前保证元素存在，`k` 在当前元素数量内，前驱 / 后继须存在；所有频数保持非负。值域从 `1` 开始，容量需覆盖最大值及后继查询所用的 `x + 1`。

## 最值查询扩展（常规+区间最值查询+单点赋值） {#s-6682f811c48c}

`update(x, v)` 只允许把单点值增大，`getMax(l, r)` 查询闭区间最大值。更新为 $O(\log n)$，当前查询在区间分解中反复扫描边界，保守按 $O(\log^2 n)$ 估计；当前初值为零，只适合非负值；需要负值时须更换初始化下界，需要任意单点赋值时使用线段树。
