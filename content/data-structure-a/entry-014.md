# KD Tree {#s-ad631548a559}

将多维点按分割平面组织成树，用子树包围盒排除或整体计入查询。当前 `query(a)` 统计每一维都不大于 `a[i]` 的点数；按方差最大的维度建树，失衡时重建。

**约定：** 数组容量 `N = 1e5 + 10`，维度为 `K`，重建阈值 `alpha = 0.725`。查询效率取决于维度和点分布，当前动态实现不应直接套用平衡静态 KD Tree 的范围查询界；最坏仍可能扫描大量节点。
