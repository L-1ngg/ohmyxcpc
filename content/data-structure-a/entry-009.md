# 主席树 (可持久化线段树) {#s-3ccf3ddb590b}

  $\mathcal{O} ( N \text{log} N )$ 建树与单点修改（每步新建一条链），查询 $\mathcal{O} ( \text{log} N )$。原理：每次修改只新建根到目标叶子的一条链（$\text{log}$ 个节点），其余子树与旧版本共享——`root[i]` 因此就是「前 $i$ 个元素」的权值线段树，区间 $[ l , r ]$ 的信息由两版本相减得到（`kth` 里的 `cnt` 相减即此）。用法：把值域离散化到 $[ 1 , m ]$，`modify(root[i] = root[i - 1], ..., 离散值)` 建版本；静态区间第 $k$ 小查询 `kth(root[r], root[l - 1], 1, m, k)`。数组开 `4 * N + 17 * N`（约 17 层/次修改），`N` 按题目改。
