# 常见例题 {#s-b05cba909125}

带修改莫队的完整例题：支持单点改色与区间不同颜色数查询。输入先离线记录，再同步移动区间端点和修改时间。

题意：（带修莫队 - 维护队列）要求能够处理以下操作：

- `'Q' l r` ：询问区间 $[ l , r ]$ 有几个颜色；

- `'R' idx w` ：将下标 `idx` 的颜色修改为 `w`。

输入格式为：第一行 $n$ 和 $q \quad ( 1 \le n , q \le 133333 )$ 分别代表区间长度和操作数量；第二行 $n$ 个整数 $a_{1} , a_{2} \ldots , a_{n} \quad ( 1 \le a_{i} \le 10^{6} )$ 代表初始颜色；随后 $q$ 行为具体操作。

带修莫队 = 普通莫队 + 时间维：查询按（左端点块，右端点块，时间）排序，`t` 指针沿时间维移动，`time()` 中用 `swap` 回溯修改；复杂度约 $\mathcal{O} ( n^{\frac{5}{3}} )$。

**数据布局：** `query` 保存 `{左端点, 右端点, 修改次数, 编号}`，`modify` 保存 `{新值, 位置}`。仅当修改位置在当前窗口内时调整颜色统计，再交换新旧值实现时间回退。
