# pbds 扩展库实现平衡二叉树 {#s-203c3d595115}

记得加上下面的头文件与命名空间。模板第三个参数是比较器（默认 `less`，改成 `greater` 即翻转顺序）。`tree` 不容许重复键，用第二维计数 `{x, ++dic[x]}` 实现可重集合（见下例）。

**常用接口：**

| 接口 | 含义 |
| --- | --- |
| `insert(x)` / `erase(x)` | 插入 / 删除键 |
| `order_of_key(x)` | 严格小于 `x` 的元素数 |
| `find_by_order(k)` | 第 `k` 个元素的迭代器，排名从 `0` 开始，越界返回 `end()` |
| `lower_bound(x)` / `upper_bound(x)` | 不小于 / 严格大于 `x` 的边界 |
| `join(other)` | 合并键域有序且不交叠的另一棵树 |
| `split(x, other)` | 将大于 `x` 的键移入另一棵树 |

**操作：** 输入编号 `1..6` 依次表示插入一个值、删除一个值、查询排名、第 `k` 小、严格前驱、严格后继；对外排名从 `1` 开始。使用 `{值, 序号}` 区分重复键。删除、排名选取与前驱后继查询须满足存在性条件后再解引用。
