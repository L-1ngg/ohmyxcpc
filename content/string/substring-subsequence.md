# 子串与子序列

| 中文名称 |   常见英文名称    |                                  解释                                  |
| :------: | :---------------: | :--------------------------------------------------------------------: |
|   子串   |  $\tt substring$  |         连续的选择一段字符（可以全选、可以不选）组成的新字符串         |
|  子序列  | $\tt subsequence$ | 从左到右取出若干个字符（可以不取、可以全取、可以不连续）组成的新字符串 |
