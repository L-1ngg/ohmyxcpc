# kmp {#s-b8fe31c3713f}

KMP 在线性时间内匹配一个模式串，并复用最长真前后缀信息处理失配。总时间为主串与模式串长度之和，也可用于周期与循环节判断。

> 应用：
>
>
> 1. 在字符串中查找子串；
>
> 1. 最小周期：字符串长度-整个字符串的 border；
>
> 1. 最小循环节：区别于周期，当字符串长度 $n \operatorname{mod} ( n - n x t [ n ] ) = 0$ 时，等于最小周期，否则为 $n$ 。

以最坏 $\mathcal{O} ( N + M )$ 的时间计算 $t$ 在 $s$ 中出现的全部位置。

**状态：** `next[i]` 是模式串前 `i` 个字符的最长真前后缀长度，`next[0] = -1` 为哨兵；数组长度为 `t.size() + 1`。
