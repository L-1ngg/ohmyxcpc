# 子序列自动机 {#s-c98e8a16e042}

  对于给定主串 $s$（长 $n$），以 $\mathcal{O} ( n )$（对每个字符开桶存出现位置）预处理、单次 $\mathcal{O} ( m \text{log} n )$ 判定长度为 $m$ 的询问串是否为 $s$ 的子序列。核心是 `next[i][c]`：位置 $i$ 之后（不含 $i$）字符 $c$ 第一次出现的位置，匹配时贪心跳转。常见用途：

1. 判断一个（或多个）串是否为主串的子序列

1. 多串各自建自动机后同步转移，求最短公共超序列等公共子序列变种

1. 在自动机上 DP 统计本质不同子序列个数

1. 配合 DP 求字典序第 $k$ 小的子序列

相比 SAM/PAM 结构简单、预处理快，适合字符集小、反复判断子序列的场景。
