# 物品装箱 {#s-3f71535419a6}

有 $N$ 个物品，第 $i$ 个物品为 $a [ i ]$ ，有无限个容量为 $C$ 的空箱子。两种装箱方式，输出需要多少个箱子才能装完所有物品。

## 从前往后装（线段树解） {#s-c550def2c256}

每个箱子容量 $C$，物品按输入顺序装进**最靠前**还能放下的箱子。线段树维护剩余容量最大值。

**容量：** 线段树与物品数组按输入规模设置，当前 `N = 1e6 + 10`。

## 选择最优的箱子装（multiset 解） {#s-f8717fd6efad}

选择能放下物品且剩余容量最小的箱子放物品。`multiset` 内部有序，`lower_bound(物品体积)` 即最小可行箱，装入后删旧容量插新容量，每步 $\mathcal{O} ( \text{log} N )$。

**删除：** 使用迭代器删除选中的一个箱子；`multiset.erase(value)` 会删除所有相同剩余容量的箱子。
