# 统计区间不同数字的数量 (离线查询) {#s-5b96dba46a80}

  核心在于使用 `pre` 数组滚动维护每一个数字出现的最后位置，配以树状数组统计数量。由于滚动维护具有后效性，所以需要离线操作，从前往后更新。时间复杂度 $\mathcal{O} ( N \text{log} N )$ ，常数瓶颈在于 `map`，用手造哈希或者离散化可以优化到理想区间；同时也有莫队做法，复杂度稍劣。[例题链接](https://www.luogu.com.cn/problem/P1972) 。
