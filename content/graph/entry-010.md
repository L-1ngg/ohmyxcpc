# 一般图最大权匹配 (带权带花树算法) {#s-b5d4b612dd0f}

  下方模板编号从 $1$ 开始，复杂度为 $\mathcal{O} ( N^{3} )$ 。调用 `work(n, edges)` 返回最大总权（`edges` 元素为 `{u, v, w}`，重边自动取权值最大者）；`match()` 返回其中一种方案的配对表（每点 $i$ 配 `lk[i]`，一个匹配边可能出现两次）。权值类型由 `typedef int T` 决定，需要时改为 `long long`。
