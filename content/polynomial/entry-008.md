# 拉格朗日插值 {#s-def5bb8b2bb4}

通过互异采样点恢复多项式值。下方实现针对连续点上的自然数幂和：$\sum_{i=1}^{k}i^n$ 是关于 `k` 的至多 `n+1` 次多项式，使用 `n+2` 个采样点插值，依赖模整数类型 `Z`。

$n + 1$ 个点可以唯一确定一个最高为 $n$ 次的多项式。普通情况：$f ( k ) = \sum_{i = 1}^{n + 1} y_{i} \prod_{i \ne j} \frac{k - x [ j ]}{x [ i ] - x [ j ]}$ 。

**采样：** `y[i]` 逐项累加 `i` 的 `n` 次幂，形成幂和多项式的采样值；依赖模整数 `Z` 和配套快速幂。
