# SMU\_inch {#s-255193ef57ab}

另一套自包含板子（`double` + `EPS=1e-9`，点类型是 `P` 不是上面的 `Point`）。`#define pop pop_back`、`#define list vector` 会污染标准名，用时小心。`N` / `MOD` 按题目改。与上文模板不要混用。

**类型与精度：** 这是 SMU_inch 的独立二维几何封装，使用自己的 `P` 和 `db`，与上方模板分别使用。`EPS` 随坐标量级选择；近似相等没有传递性，不能直接作为任意排序的等价关系。

**向量接口：** `disTo` / `disTo2` 是两点距离 / 距离平方，`abs` / `abs2` 是模长 / 模长平方；`alpha` 求极角，`rot90` 逆时针旋转 90°，`rot` 参数为弧度，`unit` 要求非零向量。点积符号区分锐角、直角、钝角；叉积符号区分逆时针、共线、顺时针。

**相交与圆：** 严格线段相交排除端点接触和重叠；投影要求直线两端点不同。圆关系返回 `0/1/2/3/4`，依次为内含、内切、相交、外切、相离；圆圆交点需先排除完全重合。公切线函数将第二半径取负可求内公切线，取零可求点到圆的切线。最小圆覆盖的线性复杂度为随机打乱后的期望界。

**多边形接口：** 点包含判断返回 `0/1/2`，依次为外部、边界、内部；严格凸包移除共线中间点，非严格凸包使用前先去重。半平面裁剪保留有向切线左侧及交点，有向面积保留顶点顺序带来的符号。
