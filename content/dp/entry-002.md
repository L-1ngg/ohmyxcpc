# 完全背包 {#s-93bf89f1ef16}

每种物品可选任意多件，在总容量不超过 `W` 时最大化价值。`w[i]` 为正体积、`v[i]` 为价值；一维实现按容量正序枚举，使当前物品能重复使用。优化后时间 $O(nW)$，空间 $O(W)$。

**思路:**

思路和**01 背包**差不多，但是每一件物品有**无限个**，其实就是从每 **种** 物品中取 \$0, 1, 2,… \$ 件物品加入背包中

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 0; j <= W; j++)
        for (int k = 0; k * w[i] <= j; k++)
            dp[i][j] = max(dp[i][j], dp[i - 1][j - k * w[i]] + k * v[i]);
```

实际上，我们可以发现，取 $k$ 件物品可以从取 $k - 1$ 件转移过来，那么我们就可以将 $k$ 的循环优化掉

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 0; j <= W; j++) {
        dp[i][j] = dp[i - 1][j];
        if (j >= w[i]) dp[i][j] = max(dp[i][j], dp[i][j - w[i]] + v[i]);
    }
```

和 01 背包 类似地压缩成一维——注意完全背包是**顺序**遍历（`dp[j-w[i]]` 用的是当轮新值，等价于可以重复取），与 01 背包的逆序相对。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= W; j++)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```
