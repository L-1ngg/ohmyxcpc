# SOSdp 高维前缀和 {#s-7d210b859861}

对位掩码做高维前缀和，在 $O(n2^n)$ 时间内求每个集合的子集和或超集和。第一段让子集贡献给超集，第二段反向汇总；转移前的数组是原始权值，转换完成后是对应包含关系的总和。

子集向超集转移

```cpp
for (int j = 0; j < n; j++)
    for (int i = 0; i < 1 << n; i++)
        if (i >> j & 1) f[i] += f[i ^ (1 << j)];
```

超集向子集转移

```cpp
for (int j = 0; j < n; j++)
    for (int i = (1 << n) - 1; i >= 0; i--)
        if (!(i >> j & 1)) f[i] += f[i ^ (1 << j)];
```
