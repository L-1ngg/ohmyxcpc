# 多重背包 {#s-baabf1543577}

  有 $n$ **种**物品和一个容量为 $W$ 的背包，第 $i$ **种**物品的体积为 $w [ i ]$，价值为 $v [ i ]$，数量为 $s [ i ]$，求解将哪些物品装入背包中使总价值最大。

**思路：**

对于每一种物品，都有 $s [ i ]$ 种取法，我们可以将其转化为**01 背包**问题

尽管采用了 **二进制优化**，时间复杂度还是太高，采用 **单调队列优化**，将时间复杂度优化至 $O ( n * m )$：按 $j \operatorname{mod} w$ 分组后在每组内做滑动窗口，窗口长度为 $s + 1$，维护 $g [ k ] - \lfloor ( k - j ) / w \rfloor v$ 的最大值。
