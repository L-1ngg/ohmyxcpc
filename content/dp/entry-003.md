# 多重背包 {#s-baabf1543577}

每种物品有数量上限 `s[i]`，体积为 `w[i]`、价值为 `v[i]`，在容量 `W` 内最大化总价值。可枚举件数、二进制拆成 01 物品，或按容量余数分组做单调队列优化；后者时间为 $O(nW)$。

**思路：**

尽管采用了 **二进制优化**，时间复杂度还是太高，采用 **单调队列优化**，将时间复杂度优化至 $O ( n * m )$：按 $j \operatorname{mod} w$ 分组后在每组内做滑动窗口，窗口长度为 $s + 1$，维护 $g [ k ] - \lfloor ( k - j ) / w \rfloor v$ 的最大值。

**思路：** 按容量对物品体积的余数分组，在旧状态 `g` 上维护单调队列；窗口允许取 `0..s` 件，超出数量上限的队首出队。
