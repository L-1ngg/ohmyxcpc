# 汉明权重 {#s-f4a9179f7623}

Gosper’s hack 按数值递增枚举含固定数量 `k` 个 1 的位掩码，常用于枚举大小为 `k` 的子集。每个状态用常数次位运算得到后继；要求掩码和中间值在整数位宽内，`k = 0` 的空集应单独处理以避免除零。

**接入：** 这是转移骨架，需要按题意填写循环体与初始状态。

```cpp
for (int i = 0; (1 << i) - 1 <= n; i++) {
    for (int x = (1 << i) - 1, t; x <= n;
         t = x + (x & -x), x = x ? (t | ((((t & -t) / (x & -x)) >> 1) - 1)) : (n + 1)) {}
}
```
