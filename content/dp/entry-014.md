# 汉明权重 {#s-f4a9179f7623}

  Gosper’s hack：按升序枚举 $[ 0 , n ]$ 中**二进制恰好含 $i$ 个 $1$** 的所有数，$\mathcal{O} ( \text{组合数} )$。外层 $i$ 从 $0$ 到 $\text{log}_{2} ( n + 1 )$，内层从最小组合 `(1<<i)-1` 通过 `t = x + (x & -x)` 的组合位技巧得到下一个同权重数，常用于枚举大小为 $i$ 的子集状态。

```cpp
for (int i = 0; (1<<i)-1 <= n; i++) {
    for (int x = (1<<i)-1, t; x <= n; t = x+(x&-x), x = x ? (t|((((t&-t)/(x&-x))>>1)-1)) : (n+1)) {
        // todo
    }
}
```
