# 二维费用的背包 {#s-36dbadb619c8}

每件物品最多选一次，同时限制总体积不超过 `W`、总重量不超过 `M`，最大化价值。状态增加重量维度，体积与重量两层均倒序枚举；时间 $O(nWM)$，空间 $O(WM)$。

**思路：**

背包的限制条件由一个变成两个，那么我们的循环再多一维即可。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = W; j >= w; j--)
        for (int k = M; k >= m; k--)
            dp[j][k] = max(dp[j][k], dp[j - w][k - m] + v);
```
